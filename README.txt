ВАЛЬХАЛЛА ТАТУ — ПАМЯТКА ВЛАДЕЛЬЦУ

1. Как менять тексты, цены, контакты и фото (без пересборки)
- Откройте файл site-config.js (в папке public/ или в готовой папке dist/) любым блокнотом.
- Меняйте нужные строки в кавычках: цены, график, адрес, ссылки на Telegram и описания услуг.
- Чтобы заменить концептуальные фото на реальные снимки студии, положите свои файлы в папку
  images/ (например, hero-hall.jpg) и укажите их имена в разделе images внутри site-config.js.

2. Запуск на своем хостинге (Reg.ru, Timeweb, Beget)
- В корне уже настроен относительный путь сборки (base: './').
- Если вносите правки в исходный код, выполните команду npm run build.
- Загрузите все содержимое папки dist/ в корневую папку сайта (обычно public_html или www).
- Файлы site-config.js и папка images/ уже находятся внутри dist/ и работают сразу.

3. Привязка домена без оплаты хостинга (Vercel / Cloudflare Pages)
- Подключите этот GitHub-репозиторий в Vercel или Cloudflare Pages (команда сборки: npm run build,
  папка результата: dist).
- В настройках DNS у регистратора домена (Reg.ru, Beget и др.) добавьте две записи:
  A     @     -> 76.76.21.21
  CNAME www   -> cname.vercel-dns.com
- После обновления DNS (обычно 15–60 минут) SSL-сертификат выпустится автоматически.
