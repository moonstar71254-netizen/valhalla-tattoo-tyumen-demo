ПАМЯТКА ПО УПРАВЛЕНИЮ САЙТОМ — ВАЛЬХАЛЛА ТАТУ

1. КАК МЕНЯТЬ ТЕКСТЫ, ЦЕНЫ И КОНТАКТЫ
Откройте файл site-config.js (в папке dist/ или на хостинге) в обычном текстовом редакторе
(Блокнот, VS Code или редактор в панели хостинга). Исправьте нужные строки в кавычках
(названия услуг, цены, график, ссылки на Telegram) и сохраните файл. Пересобирать сайт
через Node.js не нужно — изменения появятся сразу после обновления страницы.

2. ЗАПУСК НА СВОЕМ ХОСТИНГЕ (REG.RU, TIMEWEB, BEGET И ДР.)
Загрузите все содержимое папки dist/ (index.html, site-config.js и папку assets/)
в корневую директорию вашего сайта (обычно public_html или www).
Серверная часть и базы данных не требуются, все пути относительные.

3. ПРИВЯЗКА СВОЕГО ДОМЕНА БЕЗ ОПЛАТЫ ХОСТИНГА (VERCEL / CLOUDFLARE PAGES)
- Купите домен на себя у любого регистратора (Reg.ru, Timeweb, Beget).
- В панели проекта (Vercel или Cloudflare Pages) откройте Settings -> Domains и добавьте домен.
- В DNS-панели регистратора пропишите выданные записи (для Vercel обычно:
  A @ -> 76.76.21.21 и CNAME www -> cname.vercel-dns.com, либо точные значения из панели).
- Подождите 15-30 минут до обновления DNS и автоматического выпуска SSL-сертификата.
